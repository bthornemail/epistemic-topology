    About

    This interface adheres to W3C HTML 5.3, ARIA 1.3, and WCAG 2.2 AA guidance. It renders lattice levels using the shared vocabulary defined by the DANL project and highlights observability-preserving τ-products.

    Use the downloadable JSON traces generated by the Scheme orchestrator or the Prolog/Datalog verification layers to populate the timeline.
